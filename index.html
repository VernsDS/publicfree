Quick tutorial

Pilih tujuan hostingmu. Urutannya penting: siapkan hosting dulu, baru buat record DNS di sini.

VERCEL

Domain ke Vercel

  1. Deploy dulu project-mu di Vercel sampai URL *.vercel.app hidup (bukan 404).
  2. Buka Project → Settings → Domains → Add, masukkan namamu.publicfree.web.id.
  3. Vercel menampilkan nilai CNAME unik, contoh a1b2c3d4.vercel-dns-017.com. Salin nilai itu — jangan pakai cname.vercel-dns.com untuk project baru.
  4. Di sini pilih CNAME · Vercel, tempel nilai tadi, lalu buat subdomain.
  5. Balik ke Vercel, tunggu status domain menjadi Valid Configuration (1–5 menit).
  6. Klik Cek di List Domain. Kalau muncul “Aktif”, selesai.

Vercel menulis Invalid Configuration? Berarti CNAME belum cocok dengan nilai yang diminta project, atau domain belum ditambahkan di langkah 2.

VPS

Domain ke VPS

  1. Pastikan web-nya sudah ada dan jalan di VPS. Uji dari dalam VPS: curl -I http://127.0.0.1:3000 harus membalas 200.
  2. Buka firewall: ufw allow 80,443/tcp.
  3. Pasang Nginx sebagai reverse proxy ke port aplikasi (contoh di bawah).
  4. Pasang SSL: certbot --nginx -d namamu.publicfree.web.id.
  5. Di sini pilih A · VPS, isi IP publik VPS, lalu buat subdomain.
  6. Klik Cek: “Aktif (HTTP 200)” berarti DNS dan web sudah benar.
server {
    listen 80;
    server_name namamu.publicfree.web.id;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}

Kalau “Cek” bilang Tidak ada web yang merespons: aplikasinya mati, port-nya salah, atau Nginx belum jalan.
